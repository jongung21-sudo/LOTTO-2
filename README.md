# 👑 박은규의 인생역전기 (VIP 1,000,000₩ EDITION)

> **우주 주파수 & 시그니처 핑크 리본의 수호자, 마스터 박은규가 보증하는 대한민국 0.1% 하이엔드 로또 6/45 솔루션**

## 🌟 주요 핵심 기능

### 1. 🎡 박은규의 황금 회전 드럼 추첨기 (ROTATING DRUM LOTTO 6/45)
- 실제 방송용 로또 추첨기와 동일한 **원심력 & 텀블링 물리 엔진(HTML5 Canvas)** 탑재.
- 4개의 황금 배플(내부 스쿠프)을 타고 45개 볼이 뒤섞이는 역동적 텀블링 사운드(`clack-clack-rattle`).
- 드럼이 회전하며 1구씩 스쿠프에 걸려 **황금 롤링 트랙(Ball Slide Rail)** 위로 굴러 나와 거치대(1구~6구)에 안착하는 생방송 연출.
- 라이브 6구 순차 배출 모드 및 쾌속 추첨 모드 지원.
- 추첨된 6개 번호를 하단 슬립 A게임으로 원클릭 동기화.

### 2. 🧙‍♂️ 마스터 박은규 캐릭터 챔버 (Master Chamber)
- 실제 인물 사진 기반의 황금 회전 링 & 핑크 네온 글로우 오라 프레임.
- **C안 하이브리드 대사 엔진**: 영험한 도사님의 호탕한 위트와 퀀트 마스터의 근엄한 명언이 상황별로 교차 출력.
- 번호 추첨 시 황금 섬광 오라 이펙트 발동.

### 3. 📜 박은규 마스터의 인생역전 황금 부적 (神託符)
- **마스터의 신탁 (Master's Oracle)** 모드 선택 시 자동 발급되는 디지털 황금 부적.
- 오늘의 계시, 행운의 명당 방위, 행운의 구매 시간대, 금주의 수호 색상.
- 공식 **"박은규인(印)"** 붉은 낙관 인장 날인.

### 4. ⚡ 5대 전문 비기 (알고리즘 엔진 탭)
1. **마스터의 신탁**: 직관 기운 추출 + 황금 부적 증정
2. **빅데이터 통계 분석**: 1,100여 회 기출 가중치, 최다 빈출수 및 가뭄수 밸런스 필터링
3. **10만 회 몬테카를로 AI**: 실시간 100,000회 가상 난수 연산 게이지 후 분산 최적 앙상블 조합 산출
4. **VIP 사주·수비학 매칭**: 성함과 생년월일 입력을 통한 천을귀인 오행 주파수 동기화
5. **프로 커스텀 정밀 필터**: 1~45 인터랙티브 패드에서 고정수(최대 5개), 제외수(최대 15개), 총합 구간 수동 제어

### 5. 🎟️ VIP 실전 유틸리티 & 리포트
- **VIP 골드 복권 영수증**: 동행복권 6/45 슬립을 블랙&골드 메탈릭으로 완벽 재해석. **고화질 PNG 영수증 이미지 다운로드** 및 번호 복사 지원.
- **역대 당첨 백테스팅**: 과거 실제 로또 기출 50여 회차에 대입하여 1~5등 적중 횟수 및 가상 당첨금 정밀 계산.
- **Web Audio API 사운드 엔진**: 볼 롤링, 흡입/배출 팝핑, 잭팟 팡파레, 럭셔리 컨페티 축제 효과 (음소거 토글 가능).

## 🛠️ 기술 스택

- **Frontend**: React 19, Vite
- **Styling**: TailwindCSS, Glassmorphism, 3D CSS Transforms
- **Graphics & Physics**: HTML5 Canvas (Rotating Drum & Ball Tumbler)
- **Audio**: Web Audio API (Synthesized Real-time Casino & Mechanical Sounds)
- **Export**: `html-to-image` (High-resolution PNG Ticket Export)
- **Icons & FX**: `lucide-react`, `canvas-confetti`
